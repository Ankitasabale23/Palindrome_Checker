# Palindrome Checker

## 1. Objective

The objective of this task is to create a Python program that checks whether a word or sentence is a palindrome after ignoring spaces and capitalization.

## 2. Tools Used

- Python
- Visual Studio Code
- GitHub

## 3. Programming Language

Python

## 4. Description

This project is a simple Palindrome Checker developed using Python.

The program accepts a word or sentence from the user and checks whether it reads the same forward and backward.

The input is normalized by removing spaces and converting all characters to lowercase before checking.

## 5. Features

- Accepts a word or sentence
- Ignores spaces
- Ignores capitalization
- Checks whether the input is a palindrome
- Displays the result to the user
